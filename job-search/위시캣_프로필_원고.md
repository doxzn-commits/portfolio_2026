기준: ① 회사명 익명화 ② 외주 전용 ③ 효율 지표 중심 (매출액 비공개)

익명화 규칙:
- 카피아 → "수입차 커머스 플랫폼 C사"
- 핌아시아 → "이커머스 A사"
- 폴싯 → "글로벌 서비스 스타트업 B사"

## 1. 파트너 소개

### 한 줄 소개 (제목형 칸이 있을 경우)
콘텐츠 발행 성과 24배, 제작 시간 75% 절감 — 마케팅을 시스템으로 만들어드립니다

### 본문

안녕하세요. 마케팅 자동화·AI 콘텐츠 시스템을 구축하는 파트너입니다.

이커머스·플랫폼 기업 마케팅팀에서 4년간 일하며, 사람이 반복하던 마케팅 업무를
자동화 시스템으로 전환해 실측 성과로 검증해왔습니다. "도구를 만드는 개발자"가 아니라
"성과 지표를 아는 마케터가 직접 만드는 자동화"가 제 차별점입니다.

■ 제공 서비스

1. AI 콘텐츠 자동 발행 시스템 구축
   - 키워드 입력 → SEO/GEO(AI 검색 최적화) 구조가 적용된 완성 원고 자동 생성
   - 실적: 수입차 플랫폼 C사에서 월간 콘텐츠 CTA 클릭 24배 성장 (동월 동일 채널 비교)

2. 마케팅 업무 자동화 (크롤링·시트 연동·발행 자동화)
   - 엑셀/시트 데이터 → 콘텐츠 생성 → 채널 발행까지 원클릭 파이프라인
   - 실적: 콘텐츠 제작 시간 4시간 → 1시간 (75% 절감), DB 검수 2~3시간 → 5분

3. SEO/GEO 진단 및 개선
   - URL 입력 시 SEO·AI 검색 인용 가능성을 100점 체계로 진단하는 도구 직접 개발·운영
   - 진단 → 개선 우선순위 리포트 → 콘텐츠 구조 개선까지 일괄 수행

4. 마케팅 대시보드·정산 시스템 구축
   - 분산된 시트/데이터를 자동 통합, 성과·정산 현황을 단일 대시보드로
   - 실적: 정산 준비 3시간 → 실시간, 아웃리치 처리량 2배

■ 일하는 방식

- 요구사항을 "업무 흐름" 단위로 정의한 뒤, 작게 만들어 먼저 검증하고 확장합니다.
- 결과물은 실행 방법·유지보수 가이드 문서와 함께 인수인계합니다.
- 성과는 작업 완료가 아니라 지표(시간 절감, 클릭, 전환)로 보고합니다.

■ 사용 기술
Python, Playwright, Google Apps Script, TypeScript, GA4/GSC, HTML/CSS,
Google Sheets 연동, AI API(Claude 등) 활용 파이프라인

외주 프로젝트 전용으로 활동합니다. 주중 저녁·주말 포함 일정 협의 가능합니다.

## 3. 포트폴리오 6건

### P1. AI 콘텐츠 자동 발행 시스템 (SEO/GEO 기반)

- 기간: 2025.10 ~ 2026.06 (운영 중)
- 역할: 기획·구축·운영 단독 수행
- 클라이언트: 수입차 커머스 플랫폼 C사 (사내 프로젝트)
- 설명:
  수기 작성으로 정체되어 있던 콘텐츠 채널을 AI 자동 발행 시스템으로 전환한 프로젝트.
  키워드를 입력하면 SEO/GEO 표준 구조(정답 박스·질문형 H2·FAQ·JSON-LD)와 검색 색인
  성공 패턴이 반영된 완성 HTML이 생성되며, 기존 에디터로 즉시 발행되도록 설계해
  개발 리소스 없이 운영을 시작했습니다.
  · 월간 CTA 클릭 24배 성장 (동월·동일 채널 비교)
  · 이전 6개월 누적 클릭의 4.3배를 1개월 만에 달성
  · 색인 성공/실패 패턴을 생성 규칙으로 체계화 → 품질이 시스템에서 재현
- 기술: AI API 파이프라인, HTML/JSON-LD, SEO/GEO, GA4·GSC

### P2. 네이버 블로그 콘텐츠 발행 자동화

- 기간: 2026.03 ~ 2026.05
- 역할: 설계·개발 단독 수행
- 설명:
  월별 프로모션 엑셀 파일을 입력하면 브랜드별 HTML 디자인 → 섹션별 PNG 이미지 →
  정리 엑셀 → 네이버 에디터 자동 입력(임시저장)까지 완성되는 파이프라인.
  브랜드별로 다른 엑셀 양식을 키워드 기반으로 자동 감지하고, 미등록 브랜드는
  설정을 자동 생성하며, 중복 발행을 상태 관리로 방지합니다.
  · 콘텐츠 제작 시간 4시간 → 1시간 (75% 절감)
  · 검수 시간 약 50% 절감, 월 3개 브랜드 → 하루 2개 브랜드 처리 규모로 확대
- 기술: Python, Playwright, openpyxl, PIL, HTML/CSS

### P3. SEO/GEO 100점 진단 도구

- 기간: 2026.01 ~ 2026.02
- 역할: 기획·개발 단독 수행
- 설명:
  URL을 입력하면 SEO 점수와 GEO(AI 검색 인용 최적화) 점수를 각각 100점 체계로
  산출하는 진단 도구. SEO 5개 영역(기술·콘텐츠·온페이지·백링크·UX), GEO 5개 영역
  (인용 가능성·권위성·AI 친화 구조·답변 일치도·멀티소스)을 가중치 기반으로 평가하고
  JSON/HTML/Markdown 개선 리포트를 자동 생성합니다. CLI와 웹 UI를 모두 지원합니다.
  · 콘텐츠 품질 판단을 "감"에서 "점수"로 전환, 개선 우선순위 자동 도출
- 기술: TypeScript, Node.js, Express, HTML/JS

### P4. 인플루언서 정산·DB 분배 자동화 시스템

- 기간: 2025.11 ~ 2026.01
- 역할: 설계·개발·운영 단독 수행
- 설명:
  인플루언서별로 분산된 정산 시트와 상담 DB를 자동 통합·분배하는 운영 시스템.
  원본 DB에서 레퍼러 ID를 추출해 개별 시트로 자동 분배하고(연락처 마스킹·중복 방지),
  월별 실적·전환율·정산금액을 마스터 시트에 집계하며, 단일 HTML 대시보드로
  KPI·랭킹·정산 대기 현황을 시각화합니다. 수기 입력값(정산일 등)은 자동화가
  덮어쓰지 않도록 설계했습니다.
  · 정산 준비 3시간 → 실시간 확인
  · DB 검수 2~3시간 → 약 5분
- 기술: Google Apps Script, Google Sheets, HTML/JS, Chart.js

### P5. 마케팅 성과 대시보드 구축 (텍소노미 설계)

- 기간: 2024.01 ~ 2024.03
- 역할: 기획·텍소노미 설계·개발 협업 리드
- 클라이언트: 이커머스 A사 (사내 프로젝트)
- 설명:
  전사 매출과 프로젝트별 마케팅 성과를 추적하기 위한 대시보드 구축 프로젝트.
  성과 측정 기준을 수립하고 데이터 컬럼 구조(텍소노미)를 직접 설계한 뒤
  개발팀과 협업해 배포했습니다.
  · 영역별 성과 추이·전사 지표를 상시 확인하는 체계 마련
  · 보고서 취합 없이 실시간 성과 확인 가능
- 기술: 데이터 텍소노미 설계, GA·어트리뷰션 데이터 연동 기획

### P6. 체체 (cheche) — 직접 기획·개발·출시한 웹 서비스

- 기간: 2025
- 역할: 기획·개발·배포 단독 수행
- 링크: https://cheche-app.vercel.app
- 설명:
  아이디어 검증부터 UI 설계, 프론트엔드 개발, 배포까지 단독으로 수행해
  실제 사용 가능한 상태로 출시한 웹 서비스. 외주 프로젝트에서도
  "기획 문서 → 동작하는 결과물"까지 혼자 완결할 수 있음을 보여주는 사례입니다.
- 기술: React/Next.js 계열, Vercel 배포
