작성일 2026-07-24 / 상태: 포지셔닝·콘텐츠 연동 확정, 세부 매핑 확인 대기

> **확정 사항 (2026-07-24)**
> - **포지셔닝: 수입차 프로모션 비교 서비스** — 좁게 간다. 금융(계산기·제휴사 24곳·운용 1,000억)은
>   S6 신뢰 근거에서 뒷받침으로만 쓰고, 히어로·정의문·메타에는 올리지 않는다.
> - **콘텐츠 3축: 게시판 실시간 연동** — 게시판이 이미 상시 갱신되고 있으므로 수동 갱신은 쓰지 않는다.
>   소개 페이지는 게시판을 창으로 비추기만 한다.

## 0. 이 페이지가 하는 일

GNB에 들어가는 상설 페이지. 첫차 `/intro`가 앱 다운로드 한 방향으로 끝나는 것과 달리,
카피아 소개 페이지는 **끝이 아니라 분기점**이어야 한다.

```
홈 / 검색 / 게시판  →  [서비스 소개]  →  ├ 프로모션 목록
                                        ├ 게시판(핫딜·꿀팁)
                                        └ 상담 신청 · 전화
```

이유: 현재 CTA 클릭(주 572)이 검색 유입(주 191)보다 크다. 전환 다수가 검색이 아니라
**홈·직접·내부 경유**에서 나온다. 소개 페이지는 그 내부 경유 퍼널의 한가운데에 놓이는 자산이므로,
"읽고 이해시키는" 역할과 "다음 페이지로 흘려보내는" 역할을 동시에 져야 한다.

### 성공 기준 (측정 가능하게)
| 지표 | 정의 |
|---|---|
| 1차 | 소개 페이지 → 프로모션/게시판 이동률 |
| 1차 | 소개 페이지 경유 세션의 CTA 클릭 기여 수 |
| 2차 | 스크롤 깊이 75% 도달률 (이해 완료의 대리 지표) |
| 2차 | AI 검색(챗봇)에서 "카피아" 질의 시 정확 설명 여부 — 월 1회 수기 점검 |

## 1. 세 명의 독자

이 페이지는 읽는 주체가 셋이고, 셋 다 만족시켜야 한다.

**① 소비자** — 수입차를 사려는데 프로모션이 뭔지, 어디서 깎이는지 모르는 사람.
→ 어려운 금융 용어 없이 "얼마나 싸지는지"부터 보여준다.

**② AI (챗봇·AI 검색)** — 이 페이지 텍스트를 근거로 카피아를 설명한다.
→ 명시적 정의문, 구조화 데이터, 텍스트로 존재하는 숫자가 필요하다.

**③ 검색엔진** — GSC 노출을 늘리는 축.
→ 의미 있는 h1/h2, 갱신일, 내부 링크.

> **레퍼런스에서 얻은 안티패턴**: 첫차 히어로의 핵심 카피("몰라도 잘샀다")가 **이미지 안 텍스트**다.
> 실제로 페이지를 기계적으로 읽으면 "주제 텍스트 이미지"로만 잡힌다. AI 인식이 목표라면
> **히어로 카피는 절대 이미지로 만들지 않는다.**

## 2. 한 문장 정의 (이 기획의 축)

AI가 카피아를 설명할 때 그대로 인용하게 될 문장. 페이지 상단 h1 바로 아래에 `<p>` 텍스트로 배치한다.

> **카피아(Carfia)는 매달 갱신되는 수입차 제조사·딜러 프로모션을 브랜드·모델별로 모아
> 비교하고, 할부·리스·장기렌트 조건까지 함께 확인해 실구매가를 알려주는 수입차 프로모션 비교 서비스입니다.**

### 보조 정의 3종 (AI 오인식 방지)
- **표기 고정**: `카피아(Carfia)` — 첫 등장 시 1회 병기. 도메인이 carfia인데 한글은 카피아라
  AI가 "카프리오", "카랩" 등 유사 업체와 혼동한 이력이 있다. 병기가 방어선이다.
- **아닌 것 명시**: "중고차 거래 플랫폼이 아니고, 렌터카 업체도 아닙니다. 신차(수입차) 구매 조건을 비교하는 서비스입니다."
- **운영 주체 명시**: 카피아오토플랜 주식회사 · 자동차금융 10년 · 제휴 금융사 24곳.

## 3. 섹션 구조 (제안)

`[필수]` = 1차 오픈에 반드시 / `[선택]` = 2차 확장

### S1. 히어로 `[필수]`
- **h1**: 수입차, 이번 달 얼마나 싸게 살 수 있는지부터 봅니다
- **정의문**: 위 2번 한 문장 (텍스트)
- **신선도 뱃지**: `2026년 7월 프로모션 반영 완료 · 14개 브랜드 · 최근 갱신 7월 3일`
  → 소개 페이지가 죽은 페이지가 아니라는 가장 강력한 신호. AI에게도 `dateModified` 근거가 된다.
- **CTA 2단**: 1차 `이번 달 프로모션 보기` / 2차 `상담 신청` + 전화 1833-4765
- **인터랙션**: 없음에 가깝게. 진입 0.3초 fade-in만.

### S2. 왜 어려운가 (문제 정의) `[필수]`
소비자가 자기 상황을 알아보게 만드는 구간. 카드 3개.
1. 프로모션이 **매달 바뀌고** 딜러마다 다르다
2. 현금·할부·리스·장기렌트 중 **뭐가 유리한지 계산이 안 된다**
3. 정보가 브랜드 사이트·블로그·카페에 **흩어져 있다**

- **인터랙션**: 스크롤 진입 시 순차 fade-up (80ms 간격). 그 이상 금지.

### S3. 그래서 이렇게 씁니다 (How it works) `[필수 · 페이지의 하이라이트]`
4스텝. **카랩 방식**(설명 + 실제 화면)이 정답에 가깝다.

| 스텝 | 문구 | 붙는 화면 |
|---|---|---|
| 1 | 브랜드·모델 고르기 | 브랜드 그리드 스크린샷 |
| 2 | 이번 달 프로모션·할인액 확인 | 모델 상세 할인액 |
| 3 | 현금/할부/리스/장기렌트 비교 | 계산기 화면 |
| 4 | 조건 확정하고 상담 신청 | 상담 폼 |

- **인터랙션**: 좌측 스텝 텍스트 sticky + 스크롤에 따라 우측 화면이 교체되는 scroll-linked 전환.
  모바일에서는 가로 스와이프 캐러셀로 폴백.
- **주의**: 화면 이미지에는 `alt`로 스텝 설명을 그대로 넣는다(AI 인식용).

### S4. 무엇이 올라오나 — 콘텐츠 3축 `[필수 · 내부 분배 엔진]`
요청하신 "매달 프로모션 + 핫딜 + 꿀팁"이 여기에 산다. **정적 설명이 아니라 실제 최신 글을 물어온다.**

| 축 | 한 줄 정의 | 갱신 주기 |
|---|---|---|
| 수입차 프로모션 | 브랜드별 이번 달 공식 할인 조건 | 매월 초 |
| 수입차 핫딜 | 특정 모델·트림의 기간 한정 특가 | 수시 |
| 차량 꿀팁 | 실구매가·유지비·리스/렌트 비교 등 구매 판단 지식 | 주 단위 |

- **왜 라이브인가**: ① 페이지가 항상 새로워 신뢰가 오르고 ② 게시판으로 트래픽이 흘러
  기존 "홈/내부 → 게시판 → CTA" 퍼널을 그대로 강화한다. 소개 페이지가 곧 유입 분배기가 된다.
- **인터랙션**: 3축 탭 전환(데스크톱은 3열 병렬도 가능). 각 카드에 발행일 표기.

#### 연동 스펙 (확정: 게시판 실시간 연동)

게시판이 이미 상시 갱신되므로 소개 페이지는 **읽기 전용 창**으로만 동작한다. 별도 관리 지점을 만들지 않는다.

```
게시판(원천, 상시 갱신)  →  최신 N건 조회  →  소개 페이지 S4 카드
                                              (캐시 10~30분)
```

- 조회 단위: 축별 최신 **3건**, 제목 / 발행일 / 썸네일 / 링크
- 캐시: 10~30분. 매 요청마다 게시판을 때리지 않는다
- **폴백 필수**: 조회 실패 시 카드 영역을 비우지 말고 축 설명 + `전체 보기` 버튼만 남긴다.
  게시판 API(포트 4517)가 간헐적으로 죽은 이력이 있어 소개 페이지가 같이 깨지면 안 된다
- 카드 링크는 `rel` 없이 내부 링크로 — 내부 트래픽 분배가 이 섹션의 존재 이유다

#### 축 ↔ 게시판 매핑 (확정)

| 소개 페이지 축 | 게시판 | URL | 역할 |
|---|---|---|---|
| 수입차 프로모션 | 신차 프로모션 | `/board/new-car-promotion` | **주축** |
| 수입차 핫딜 | 핫딜 | `/board/hotdeal` | **주축** |
| 차량 꿀팁 | 차량꿀팁 | `/board/cartip` | **주축** |
| (부축) 차량 뉴스 | 뉴스 | `/board/news` | 하단 텍스트 링크 |
| (부축) 모델 상세 정보 | 뉴스-모델 | `/board/news-model` | 하단 텍스트 링크 |

주축 3개만 카드로 펼치고, 뉴스·모델정보는 S4 하단에 `차량 뉴스 · 모델 상세 정보도 함께 보기` 한 줄로 붙인다.
5개를 병렬로 늘어놓으면 소개 페이지의 메시지가 흐려지고, 지목된 3축이 실제로 구매 의사결정에 직결된다.

#### 축별 카드 설계 — 게시판마다 성격이 달라 포맷을 통일하지 않는다

실제 게시판을 열어보니 세 축의 콘텐츠 형태가 완전히 다르다. 같은 카드로 찍어내면 각각의 강점이 죽는다.

**① 수입차 프로모션 — 카드 3장이 아니라 `브랜드 그리드`**
제목 패턴이 `2026년 7월 {브랜드} 프로모션 신차 할인 조건 총정리`로 **브랜드 × 월 단위로 완전히 규칙적**이다.
최신 3건만 뽑으면 볼보·랜드로버·아우디만 보이고 나머지 브랜드 사용자는 자기 차를 못 찾는다.
→ **이번 달 브랜드 로고 그리드**를 깔고 각 로고가 해당 브랜드 프로모션 글로 직행하게 한다.
사용자가 자기 브랜드를 즉시 찾아 들어가므로 내부 분배 효율이 카드 방식보다 크게 높다.
- 헤더: `2026년 7월 프로모션 · {N}개 브랜드 갱신 완료`
- 미갱신 브랜드는 회색 처리하거나 지난달 글로 연결 (빈칸을 남기지 않는다)

**② 수입차 핫딜 — `할인액을 주인공으로`**
제목에 이미 금액이 박혀 있다 (`A6 40 TFSI … 최대 1,116만원 할인`).
→ 카드에서 **`1,116만원` 를 가장 큰 타이포로** 올리고 모델명을 그 아래 둔다. 제목 그대로 흘리지 않는다.
- 최신 3건, `기간 한정` 뱃지, 발행일 명기
- 이 섹션이 페이지 전체에서 액센트 컬러를 가장 강하게 쓰는 곳

**③ 차량 꿀팁 — `질문형 제목 그대로`**
`전기차 살까 리스할까`, `신차 실구매가, 차값 말고 뭐가 더 붙나` — 제목 자체가 사용자의 질문이다.
→ 가공 없이 제목을 그대로 노출한다. 썸네일 작게, 텍스트 위주 리스트형.
- 최신 3건. S7 FAQ와 주제가 겹치므로 **FAQ 답변 끝에서 해당 꿀팁 글로 연결**하면 두 섹션이 서로를 밀어준다

### S5. 실구매가 미니 계산 `[선택 · 차별점]`
"비교 서비스"라는 주장을 그 자리에서 증명하는 구간.
- 모델 선택 → 월 납입금 3개(할부/리스/장기렌트) 즉시 표시 → `자세히 계산하기`로 계산기 이동
- 없으면 S3 스텝3의 스크린샷으로 대체 가능. 있으면 체류·신뢰 모두 크게 오른다.

### S6. 믿을 근거 (Proof) `[필수]`
금융이 걸린 서비스라 이 구간이 전환의 실질 잠금 해제 지점이다.

- **숫자 4개** (회사소개 실측치): `업력 10년` `누적 고객 6,800명+` `운용 규모 1,000억원+` `제휴 금융사 24곳`
- **브랜드 로고 스트립**: 취급 14개 수입차 브랜드
- **후기 4~6건**: 차종 + 구매방식(리스/장기렌트) + 날짜 명기 — 카랩 후기 카드 포맷이 좋은 참고
- **사업자 정보**: 상호·대표·등록번호. 금융상품 중개라면 등록증 고지 위치도 여기.
- **인터랙션**: 숫자 카운트업 (단, **DOM에는 최종 숫자가 텍스트로 존재**해야 AI가 읽는다).
  로고는 아주 느린 마퀴 또는 정적 그리드.

### S7. FAQ `[필수 · AI 인식의 핵심]`
6~8문항. **AI가 발췌하기 가장 좋은 형식**이면서 소비자 이해도 같이 해결한다.

- 카피아는 어떤 서비스인가요? *(← 정의문 재수록. 이 문항이 있고 없고가 AI 답변 정확도를 가른다)*
- 이용료가 있나요?
- 프로모션 정보는 얼마나 자주 갱신되나요?
- 할부·리스·장기렌트 중 뭐가 유리한가요?
- 상담 신청하면 어떻게 진행되나요?
- 어떤 브랜드를 취급하나요?
- 개인 신용조회에 영향이 있나요?
- **인터랙션**: 아코디언. 단 `details/summary` 또는 접힘 상태에서도 DOM에 답변 텍스트가 존재하게.

### S8. 최종 CTA `[필수]`
- 주: `이번 달 프로모션 확인하기`
- 부: `상담 신청` / `1833-4765`
- 모바일은 스크롤 40% 지점부터 하단 고정 바 노출.

### S9. 푸터 `[필수]`
사업자 정보, 개인정보처리방침, 금융 관련 고지, 관련 페이지 링크.

## 4. AI 인식 설계 (별도 체크리스트)

요청하신 "AI가 카피아를 명확히 인식" 요건은 디자인이 아니라 마크업에서 결정된다.

- [ ] **h1 직후 첫 문단이 정의문** — AI 요약은 문서 앞부분에 크게 가중치를 둔다
- [ ] **핵심 카피를 이미지에 넣지 않는다** (첫차 안티패턴)
- [ ] **h2가 의미를 담는다** — "SECTION 02" 같은 무의미 헤딩 금지
- [ ] **JSON-LD 4종**: `Organization`, `WebPage`(+`dateModified`), `Service`, `FAQPage`
- [ ] **숫자는 텍스트**로 존재 (카운트업 애니메이션은 시각 효과일 뿐)
- [ ] **표기 통일**: 페이지 전체에서 "수입차 프로모션 비교" 문구를 흔들지 않는다
- [ ] **이미지 alt** 전부 서술형
- [ ] **갱신일 노출** — 화면과 메타 양쪽에
- [ ] `llms.txt` 검토 (사이트 루트, 서비스 정의 요약 제공)

## 5. 디자인 · 인터랙션 원칙

**톤**: 자동차 금융. 화려함보다 **정돈된 신뢰**. 첫차의 팝한 톤보다 카랩 쪽이 가깝다.

- 컬러는 중립 그레이 스케일 + **액센트 1색**(브랜드 컬러). 할인액·강조 숫자에만 액센트를 쓴다.
- 여백을 크게. 섹션 간 수직 리듬을 일정하게(예: 데스크톱 120px / 모바일 72px).
- **인터랙션은 정보 전달을 돕는 것만 남긴다**
  - 채택: 스크롤 연동 스텝 전환(S3), 숫자 카운트업(S6), 순차 fade-up(전역), 아코디언(S7)
  - 배제: 패럴랙스 남발, 자동재생 영상, 커서 추적, 과한 3D — 금융 신뢰도를 오히려 깎는다
- `prefers-reduced-motion` 대응 필수.
- **모바일 우선.** 게시판 유입 대부분이 모바일이므로 모바일에서 먼저 완성한다.
- 성능 목표: LCP 2.5초 이내. 히어로 이미지 프리로드, 스크린샷은 지연 로딩.

## 6. 제작 순서

1. **정의문·카피 확정** (이 문서 2번) — 이후 모든 게 여기서 파생된다
2. 와이어프레임 (모바일 → 데스크톱)
3. 콘텐츠 3축 연동 방식 확정 (결정 B)
4. 카피 전문 작성 + FAQ 8문항
5. 디자인 시안
6. 퍼블리싱 + JSON-LD
7. GNB 삽입 및 내부 링크 연결
8. AI 인식 점검 — 챗봇에 "카피아가 뭐야" 질의해 답변 정확도 확인

## 7. 결정 현황

### 확정
**A. 포지셔닝 폭 → 수입차 프로모션 비교 (좁게)**
메시지가 선명하고 AI 인식률이 높다. 금융은 S6 신뢰 근거에서 뒷받침으로만 쓴다.

**B. 콘텐츠 3축 연동 → 게시판 실시간 연동**
게시판이 상시 갱신되므로 소개 페이지는 창 역할만 한다. 세부는 S4 연동 스펙 참조.

**B-1. 축 ↔ 게시판 매핑 → 확정.** 핫딜은 전용 게시판(`/board/hotdeal`)이 이미 있다.
주축 3개(프로모션·핫딜·꿀팁) + 부축 2개(뉴스·모델정보)로 정리. (S4 매핑 표)

### 남은 항목
**E. 게시판 목록 조회 수단** — 소개 페이지가 5개 게시판의 최신 글을 어떻게 읽을지.
발행에 쓰는 API(포트 4517)에 목록 조회가 있는지, 없으면 별도 엔드포인트가 필요한지 확인 필요.
서버사이드에서 캐시해 받는 형태를 전제로 한다.

**F. 부축 노출 수위** — 뉴스·모델정보를 한 줄 링크로 둘지, 아니면 아예 빼고 3축만 남길지.

**C. S5 실구매가 미니 계산기 포함 여부** — 기존 계산기 재활용 가능 범위에 달림

**D. GNB 메뉴 라벨** — `서비스 소개` / `카피아 소개` / `카피아란?`
→ AI·검색 관점에서는 `카피아 소개`가 브랜드명을 포함해 유리
