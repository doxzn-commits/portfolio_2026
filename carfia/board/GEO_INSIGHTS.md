## ① 인용의 본질 — 결정론이 아니라 확률

| | |
|---|---|
| **시도** | 수입 전기차 라인업 글 발행 — "2026 수입 전기차 대전: BMW iX3·벤츠 GLC·테슬라·지커 7X" |
| **결과** | 검색어 **"2026년 주목 수입 신차 라인업"** 으로 AI 인용에 실제로 걸림. 결정타는 H2 **"그 외 2026 주목 수입 신차 라인업"** 이 검색어와 거의 **1:1**이었던 것. **그런데 다음 날 같은 검색어의 AI 답변이 완전히 달라짐** |
| **적용** | 인용은 켜짐/꺼짐(binary)이 아니라 **노출마다 흔들리는 확률**. 평가는 단일 체크가 아니라 **N일 · N쿼리 점유율(share of voice)** 로 → H2·FAQ 질문을 독자가 **실제 칠 검색어 그대로** 쓴다 |

## ② 신선도 — "어제 걸렸다 오늘 빠짐"의 1차 원인

- **관측**: 걸렸던 글이 며칠 뒤 밀림. **"주목 / 신상 / 최신"** 류 쿼리일수록 심함
- **원인**: AI가 이 쿼리에서 **최신성을 강하게 재랭킹**. 날짜 고정 글은 시간이 갈수록 밀린다
- **적용**: `datePublished` / `dateModified` 필수. **글을 갱신할 때마다 `dateModified`를 그날 날짜로** 올림. 주기적 갱신으로 방어

## ③ 구조화 데이터 — 빈 Product 노드가 노출을 죽였다

| | |
|---|---|
| **시도** | 프로모션 글이 모델마다 가격·재고 없는 **빈 `@type:Product` 노드**를 생성 |
| **결과** | 서치콘솔이 "offers / review / aggregateRating 누락" 경고(빨간불) → **검색 노출 안 됨** |
| **수정** | `Product` → **`Thing`** 으로 변경 + `dateModified` 당일 갱신 → 다음날 오전, **약 16시간 만에 재색인 / 노출 회복** (방향이 맞았음이 실증됨) |
| **적용** | **가격·offers 없이 Product 선언 금지.** 비-상품 엔티티는 `Thing`. + FAQPage 스키마는 본문 `<details>`와 **개수·텍스트 1:1 동기화** (뉴스 7건, 기획·프로모션 5~7건) |

## ④ 쿼리형 헤딩 증식 + 수치 정확성

**진입점 확대**
한 글에 **서로 다른 검색어를 노린 H2 / FAQ를 여러 개** 심어 인용 진입점을 늘린다.

**수치**
주행거리·가격·판매량·연비 등은 **제조사 공식 / 정부기관**(`ev.or.kr`, KAMA 등) 값과 일치해야 한다.
틀리면 재검색마다 채택이 들쭉날쭉해지고 신뢰 리스크가 생긴다.
→ **추측 수치 금지.** 웹 검색 팩트체크 후 기재하거나 **범위로**.

**확률 감각** ⚠️ *역산 추정치 — 실측 아님*

| 조건 | 추정 인용률 |
|---|---|
| FAQ스키마 + 고유수치 + 표 + 공식출처를 다 갖춘 **헤드 검색어** 글 | 20%대 |
| 일반론만 | 8% |
| **롱테일** | 35~55% |

> 도메인 권위·색인이 천장이다. 이 숫자들은 **역산한 감각**이지 측정값이 아니므로, 외부에 인용하지 말 것.

## ⑤ 포맷 실험 — 디스커버 첫 노출

- **시도**: "자율주행 총정리"를 **멀티브랜드 × 판도(누가 앞서나)형** 포맷으로 작성
- **결과**: 구글 **디스커버 첫 노출**
- **적용(가설)**: 멀티브랜드 비교 × 판도형 앵글이 디스커버에 유리할 수 있다 + `og:image` 보강 여지 → **계속 관찰해 데이터화**

## ⑥ 앵글 다양화 — 성공 포맷을 반복하지 않는다

- **시도**: 성과 좋았던 "테슬라 BSM 배터리" 후속을, 같은 걸 반복하지 않고 **트림별 배터리(LFP vs NCM) 선택 가이드**라는 새 앵글로
- **적용**: 한 포맷·한 공식에 **고착하지 말고 차별화 앵글을 의도적으로 시도** → 각각의 인용 여부를 관찰해 축적

> **이게 핵심 학습 태도다.** 대전제와 같은 말이다.

## ⑦ 주제 선택 — 중복 잦은 축을 피한다

- **관측**: 판매량·가격 **"순위"형은 남들도 많이 써서 중복이 잦다**
- **적용**
  - 리토픽/신규 전에 **이미 쓴 글 + 예정 주제와 중복 대조 필수**
  - **구매결정·비교형이 상대적으로 안전**
  - 같은 브랜드/클러스터를 하루에 몰지 말고 **분산**

# 원고 자체를 만드는 규칙

## ⑧ 문체 · 톤

- **존댓말(합니다체) 기본. 한다체 금지.** 단 AI식 헤지·양비론("~일 수도 있고 아닐 수도")은 걷어낸다
- 메타에 **출처 매체명 · "재구성" 텍스트 금지**, 면책·원문링크 footer **전체 제외**
- **독자를 특정층으로 단정하지 말 것** (예: 국산차 글을 수입차 독자용으로 좁히지 않음) — 시사점은 **리스·장기렌트·할부·구매 비교 관점으로 일반화**

## ⑨ 강조 표준 — 절제가 핵심

```css
mark { background:#fff3bf; color:#191f28; padding:1px 4px; border-radius:4px; font-weight:700 }
.hl  { color:#3182f6; font-weight:800 }
```

- 노란 형광펜(`<mark>`) + 볼드
- **칠할 대상**: 핵심 결론·TL;DR 한 줄, 검증된 수치/가격, 의사결정 키워드**만**
- **한 단락에 형광펜 1~2곳.** 전부 칠하면 강조 효과가 사라진다

## ⑩ 시각 분절 — "논문 느낌" 금지

- 텍스트만 나열하지 말고 **표 · 콜아웃 박스 · 번호 카드(steps) · 요약 칩(chips) · 히어로 밴드**로 분절
- **비교 내용은 반드시 `<table>`** — AI가 비교/총정리 쿼리에서 **표를 통째로 인용**한다
- 판매량·통계 기사엔 **막대 차트 시각화 필수** (초입 후킹 차트 + 섹션별), 순수 HTML/CSS 인라인
- 상단·하단에 **AI가 그대로 들어올릴 1~2문장 결론** (TL;DR / 핵심요약 박스)

## ⑪ 분량

기획/가이드형 본문 **2,500~3,500자**.
1,500자대면 얇은 콘텐츠로 판정될 우려 → 표 · H3 · FAQ 6~7개 · 고유 데이터로 보강.

## ⑫ CTA — 주제별 on/off

- 신차·리스·렌트로 **자연스럽게 연결되는 주제만** CTA
- 순수 정보·교통법규 등은 **생략** (억지 연결 금지)
- **보험 상담/조건 점검 표현 금지**
- 제목은 **연·월 접미 제거가 디폴트** (신선도는 날짜 메타가 담당)

## ⑬ 고유 데이터를 무기로

- **관측**: 남들이 못 쓰는 1차 데이터가 인용·차별화에 강하다
- **적용**: 리스/구매 글엔 **카피아 리스 실가격** 같은 고유 수치를 박아 넣는다 (예: 모델Y 월 46만~)
- **새 환경이라면** 당신만 가진 1차 데이터/실측치를 같은 방식으로 심어라
