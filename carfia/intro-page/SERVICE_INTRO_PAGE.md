## 페이지 구조 (구현 완료)

브레드크럼 `홈 › 카피아 소개` → 챕터 번호 01~06로 "설명서" 톤.

| # | 섹션 | 핵심 |
|---|---|---|
| S1 | 소개 헤더 | h1 + **정의문(AI 인용용)** + 스펙표(다루는것/브랜드/갱신/이용료) + CTA |
| S2 | 01 이런 분께 | 문제 제기가 아니라 "이런 분께 권합니다" 카드 3장 |
| S3 | 02 사용 방법 | **스크롤 연동 4스텝** + 우측 목업 화면 교체 (모바일은 목업 상단 고정) |
| S4 | 03 제공하는 것 | 프로모션/핫딜/꿀팁을 **"이런 걸 제공합니다"로 소개** (실제 글 미노출) |
| S5 | 04 미리 체험 | 차량 선택 → 할부/리스/렌트 월납입금 즉시 비교 (예시) |
| S6 | 05 믿을 근거 | 카운트업 4수치 + 브랜드 로고 + 후기 + 사업자·금융 고지 |
| S7 | 06 FAQ | 8문항 아코디언 (첫 문항 = 정의문 재수록) |
| S8 | 최종 CTA | 프로모션 확인 / 상담 / 전화 |
| S9 | 푸터 | 게시판 링크 + 사업자정보 + 갱신일 고지 |

- **색상**: 대표 팔레트 확정(2026-07-27) — **대표 초록 `#00eb2b`**(primary),
  빨강 `#f03d3e`(할인·핫딜 금액), 파랑 `#1e00ff`·하늘 `#1f95ed`·노랑 `#fffc57`(보조).
  잉크 `#11181C`, 서피스 `#F7F8F8`, 라운드 8·12px, 폰트 Inter+Pretendard.
  ※ 밝은 초록은 흰 배경 텍스트로 안 읽혀서 규칙을 둠: **채움(버튼·활성)=밝은초록+다크텍스트**(대비 9.9:1),
  **링크·라벨=짙은초록 `#06841f`**(대비 4.85:1). 초기 파랑→레드 시안은 폐기.
- **S4 방식**: 라이브 게시판 피드 ❌ → **소개형 카드** ✅ (하위 상세페이지라 실제 글 나열 불필요)
- **게시판 매핑**: 프로모션 `/board/new-car-promotion` · 핫딜 `/board/hotdeal` · 꿀팁 `/board/cartip`
  (+ 부축 뉴스 `/board/news` · 모델정보 `/board/news-model`)
- **AI 인식 마크업**: h1 직후 정의문 텍스트, 핵심카피 이미지금지, JSON-LD 5종
  (Organization/WebPage+dateModified/Service/FAQPage/BreadcrumbList), 숫자는 DOM에 텍스트로,
  FAQPage가 화면 FAQ와 같은 소스(data.ts) 사용.
- **반응형**: 모바일 375px 검증 — 가로 오버플로 0, GNB 자동 숨김, 목업 상단 고정 전환.
- **인터랙션(4종만)**: 스크롤 연동 스텝 / 계산기 / 카운트업 / 아코디언. + 진행바·모바일 고정CTA.
  패럴랙스·자동재생영상 배제. `prefers-reduced-motion` 대응.

## 남은 결정·작업

- **게시판 목록 조회 수단** — data.ts를 실데이터로 바꿀 때 필요. 발행 API(포트 4517)에
  목록 조회가 있는지 원격 확인 필요. (지금은 상수로 동작) ※ 소개형이라 당장은 없어도 무방
- **GNB 라벨** — `카피아 소개`로 가정. AI·검색상 브랜드명 포함이 유리
- **S5 미니 계산기** — 실제 계산기 재활용 범위에 따라 로직 교체 여부
- **계산기 수치는 예시** — 화면·푸터에 "예시 계산" 명시함. 실조건 아님 (검증 불필요 항목)
- **후기 4건은 샘플** — 실제 후기로 교체 전까지 예시. [[carfia-backup-work-log]]의
  "수치는 원천으로만 검증" 원칙과 별개(정성 후기)이나, 공개 전 실제 후기로 대체 권장
